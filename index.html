Note 数式変換ツール

TeX 形式の数式を note.com 記事用の形式に変換します。ローカル処理のみ・外部通信なし。

TeX → Note 数式変換

入力欄に TeX 形式のテキストを貼り付けて「変換」を押してください。
インライン数式 $...$ は $${...}$$ に変換します。 ディスプレイ数式 $$...$$ は $$ と数式と $$ をそれぞれ独立した行に分割します。 { } の内側にスペースは入りません。

変換規則

種類 TeX 形式 Note 形式 備考
ディスプレイ数式 $$...$$ $$ / 数式 / $$ を各行に分割 前後の空白はトリム
インライン数式 $...$ $${...}$$ 前後の空白はトリム
